Installation

When you first start the application, it will ask you if you want to download the dictionary. This is optional but strongly recommended unless you are reaching a critical level of memory space on your Android device (you can always delete that dictionary later if you decide to do so).

Also, in different parts of this application, you will need to type Chinese characters. There are different tools to do that. If you do not already have one installed, maybe the easiest and most popular is the Google Pinyin Input
